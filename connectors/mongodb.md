# MongoDB

**Status: planned. Timing to be determined.**

MongoDB is not available as a CorpusIQ connector today. There is no connect
flow, no credentials form, and no tool behind it, so this page no longer walks
you through a setup that does not exist.

The date is unconfirmed and will be driven by customer demand. If MongoDB is the
system you need first, tell us at [info@corpusiq.io](mailto:info@corpusiq.io) and
say which collections and questions matter. That demand is what moves it up the
list.

## What it will do when available

- Read-only queries across the collections you authorize, asked in plain English.
- Document structure and sampled fields surfaced so you can see what is queryable.
- Answers that cite the query used, so you can check the result before acting.

It will follow the same model as our live database connectors: read-only access,
no write operations, no schema changes.

## Live database connectors today

These are connectable now:

- [PostgreSQL](/connectors/postgres)
- [Microsoft SQL Server](/connectors/mssql)
- [Azure Cosmos DB](/connectors/cosmosdb)

See the full list on [Connectors](/connectors).
