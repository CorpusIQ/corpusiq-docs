Hermes Agent v0.20.0 (v2026.8.3)

Release Date: August 3, 2026 · Since v0.19.1: ~945 commits · ~300 files changed · 82 contributors

The Herald Release. Voice becomes conversational, Hermes talks to other agents, research gets citations you can verify, the desktop becomes a platform, and the CLI gets a power-user upgrade.

Highlights

  • Streaming Conversational Voice with Barge-In — Clause-by-clause TTS synthesis, interrupt by voice mid-sentence, busy-aware silence detection.
  • Wake Words & Hands-Free Control — Open-vocabulary wake phrases, on-device detection, multi-profile voice routing.
  • Voice on Every Platform — Voice notes on WhatsApp, Feishu, DingTalk, LINE, QQ, Photon, Weixin with auto-TTS replies.
  • Grounded Citations & Fact-Checking — Matches quotes against actual page text, links citations to exact evidence.
  • Outbound Webhooks — Push signed lifecycle events to any HTTP endpoint with HMAC signatures.
  • Desktop Becomes a Platform — Artifacts (sandboxed live preview), plugin SDK (Kanban founding plugin), global-hotkey quick-entry.
  • Agent-to-Agent Protocol (A2A v1.0) — Bundled plugin. Hermes discovers, talks to, and is driven by other A2A-compatible agents.
  • CLI Power-User Wave — ! shell mode, /init, /diff, /context, /focus, Ctrl+S stash, hermes import-agent.
  • Mid-Turn Redirects — Correct the agent while it works without losing context.
  • Tools That Fix Themselves — Truncated output recovery, patch no-op detection, search near-miss probes, write verification.
  • Smarter Compression — Proactive tool-result pruning, per-turn micro-compaction, N-user-message tail guarantee.
  • Smart Approvals — hermes approvals suggest, consecutive-denial circuit breaker, operator-customizable policies.
  • Faster Everywhere — Cold start ~14s → ~1.8s, config reads 54× faster, desktop 60fps at scale.

Voice & Speech

  • Streaming conversational TTS with barge-in across all surfaces
  • On-device wake words with open-vocabulary phrases + multi-profile voice routing
  • Fully configurable STT with hermes tools category, GUI toggles, OpenAI gpt-transcribe
  • Platform-aware auto-TTS on WhatsApp, Feishu, DingTalk, LINE, QQ, Photon, Weixin

Core Agent & Architecture

  • Proactive tool-result pruning, per-turn micro-compaction, N-user tail guarantee
  • Prompt caching on native Anthropic, DeepSeek, and OpenCode gateways
  • Cold-start ~14s GIL stall mitigated; turn flush batched into one SQLite transaction
  • Default tool iteration limit 90 → 500; tool_search validates blind tool_call args
  • Terminal truncation recovery, patch already-applied detection, search near-miss recovery

Desktop App — The Platform Wave

  • Artifacts: versioned cards, sandboxed live preview, right-rail viewer
  • Plugin SDK: Kanban founding plugin, ctx.download, widget-app SDK
  • Quick-entry window via global hotkey; multiple GUI windows; floating pane placement
  • 60fps streaming independent of transcript length; idle CPU near zero in background

CLI, TUI & Dashboard

  • ! shell mode, /init, /diff, /context, /focus, Ctrl+S stash
  • hermes import-agent — one-command migration from Claude Code/Codex CLI
  • Dashboard with lazy-loaded routes + GROUP BY session stats
