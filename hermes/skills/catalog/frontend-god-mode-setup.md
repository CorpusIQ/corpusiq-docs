# Frontend God Mode - Setup Guide

**Source:** [shawnchee/frontend-god-mode](https://github.com/shawnchee/frontend-god-mode) (15⭐, pushed May 10, 2026)

**Quality Tier:** 🔵 Community (no skills.sh security verdicts published - verified Sep 27, 2026)

Frontend God Mode packages "every famous frontend design skill in one skill" - a curated bundle of design directives from well-known frontend design skill suites, compressed into a single installable skill. The value proposition is a one-shot design-quality boost for agent-generated UI: one install applies a broad set of polish rules (spacing, typography, motion, visual hierarchy) instead of installing a dozen separate design skills.

---

## Installation

```bash
npx skills add shawnchee/frontend-god-mode
```

## What It Provides

- A combined design-rule bundle sourced from popular frontend design skills
- One-shot polish pass on agent-generated HTML/CSS/React output
- Lightweight alternative to full design suites (one skill vs 100+)
