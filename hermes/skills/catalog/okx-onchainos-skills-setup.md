# OKX OnchainOS Skills - Setup Guide

**Source:** [okx/onchainos-skills](https://github.com/okx/onchainos-skills) (338⭐)
**Skill family:** `okx/onchainos-skills` (6 indexed skills)
**Combined Installs:** ~223,489 across indexed listings (Sep 29, 2026 snapshot)
**Category:** Finance
**Quality Tier:** 🟡 Unverified (no skills.sh Trust Hub / Socket / Snyk verdicts published - verified Sep 29, 2026)

OKX publishes this official skill family for AI agents that need to integrate with the OKX OnchainOS API, covering wallet operations, token and DApp discovery, market data, DEX swaps, and transaction broadcasting. Indexed skills include okx-dex-market, okx-agentic-wallet, okx-dapp-discovery, okx-agent-payments-protocol, and okx-growth-competition. The cluster is the largest crypto skill family on skills.sh, with roughly 223K combined installs.
