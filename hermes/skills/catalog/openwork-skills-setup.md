Openwork describes itself as the free, open-source alternative to Claude Cowork and Codex: a desktop app (macOS, Windows, Linux) built on OpenCode where AI agents do real work on your files, and where teams share skills and MCP servers. The indexed skill family spans opencode primitives, an opencode bridge, SolidJS patterns, opencode mirroring, and openwork core guidance. Note the repository's default branch is `dev`, where the README and skills live.
