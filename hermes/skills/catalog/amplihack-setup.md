Amplihack is a framework for agentic coding that supports many popular agent coding tools, and skills.sh indexes a specialist analyst cluster inside it. Indexed skills include cybersecurity-analyst, lawyer-analyst, psychologist-analyst, mermaid-diagram-generator, and pptx. Note: the repo README (fetched Sep 29, 2026) states the Python repository is deprecated and rewritten in Rust as amplihack-rs, so these indexed skills live in a legacy codebase.
