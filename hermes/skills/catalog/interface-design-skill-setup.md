Interface Design teaches agents to build product interfaces with the craft of a top design team (Linear, Vercel, Stripe, Apple). The core argument: generic output happens because intent lives in prose while code generation pulls from patterns. The skill forces intent exploration, domain exploration, whisper-quiet layering, and systemic decisions before any code.

## What It Provides

| Capability | Notes |
|---|---|
| Intent exploration | Identify the specific human user, core task, and emotional quality before code |
| Domain exploration | Product-specific concepts, color worlds, and signature elements |
| Subtle layering | Surface elevation, border progression, and token architecture without harsh jumps |
| Infinite expression | Reject identical patterns; every interface emerges from its task |
| Systemic intent | Color, spacing, depth, and typography reinforce one stated feel |

Scope: dashboards, admin panels, SaaS apps, tools, settings pages, data interfaces. Explicitly not for landing pages or marketing sites.
