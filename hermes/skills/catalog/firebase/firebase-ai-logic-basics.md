# Firebase AI Logic Basics

Firebase AI Logic, the successor to Vertex AI for Firebase, integrated into mobile and web apps so clients call Gemini models directly.

## Setup

```bash
npx skills add firebase/agent-skills@firebase-ai-logic-basics
```

## Capabilities

- Add Firebase AI Logic to Android, iOS, Web and Flutter apps
- Configure model selection and client-side calls to Gemini
- Apply the app-side guardrails the skill documents
