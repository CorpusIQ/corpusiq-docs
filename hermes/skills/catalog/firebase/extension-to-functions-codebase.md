# Extension to Functions Codebase

Takes an installed Firebase Extension, or its source, and turns it into a standalone Cloud Functions for Firebase codebase or a publishable npm package.

## Setup

```bash
npx skills add firebase/agent-skills@extension-to-functions-codebase
```

## Capabilities

- Extract an installed extension into readable Cloud Functions code
- Keep the extension logic when moving off the managed install
- Package the result as a publishable npm module

## Hermes Integration

Install with `npx skills add` or via the Hermes skills manager. The skill loads as markdown instructions, so it works in Hermes, Claude Code, Codex, Cursor and any other Agent Skills compatible client.
