# New Skills - November 8, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills across 0 failed queries: 81 NEW rows and 256 PARTIAL, with the top NEW row at 327 installs and nothing above the 1,000-install trigger. That is the forty-second consecutive silent window.

The trending board served 600 rows across 67 sources. Three sources had no catalog page and all three sat under 1,000 installs, so the board carried nothing above the floor either.

Both standard lanes were therefore silent, and the November 8 morning fire had already drained the candidate queue it inherited. This fire probed fresh territory instead: 131 topic queries across domains the standing window never asks about, 9,453 unique rows after de-duplication, 2,269 distinct sources. Exactly 10 sources cleared the 5,000-install window total. Two carry standing dispositions (a security exclusion and a Snyk critical finding), one is a domain-only source with no repository to document, and one turned out to be an existing catalog page whose September snapshot was badly stale, which leaves six new publishers documented here plus one page refreshed.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata, the real skill layout read from a shallow clone and the frontmatter description of every indexed skill. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 21 gate runs passed on the orchestrator re-run against the canonical scripts, with no fix cycles beyond three prose corrections made before integration.
