# New Skills - November 8, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills across 0 failed queries: 81 NEW rows and 255 PARTIAL, with the top NEW row at 321 installs and no NEW source anywhere near the 1,000-install trigger.

The trending board served 600 rows across 63 sources, and every one of those sources already has a catalog page, so the board carried nothing new.

Both standard lanes were therefore silent, and this fire drained the candidate queue the November 7 evening probe left on disk instead of probing again. That queue held 133 sources sized by repository, 32 of them at or above the 5,000-install floor. Two carry standing dispositions, two repositories no longer clone, one publisher's listings carry Chinese skill names that the pack cross-check cannot parse, and one is a private vendor marketplace for a single company, which leaves twelve documented here for 91,452 combined installs across 93 indexed listings.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from a shallow clone, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 36 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
