# New Skills - November 4, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 884 unique skills with 0 failed queries: 81 NEW rows across 57 sources and 260 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 308 installs. That makes the thirty-fourth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 71 sources with a single uncovered source, archify.si, a domain with no repository and 1,156 board installs. Neither lane produced a convert, so the fire drained the sized-candidate queue the November 3 evening topic probe left behind.

That queue held 228 sources sized by their own repository, 93 of them above the 5,000-install floor. Re-testing all 93 against the current catalog tree found 66 without a catalog page; 56 remained after removing the standing dispositions, and the top 20 were cloned and verified before drafting. Sixteen were documented here on install weight: the official Microsoft VS Code and PyTorch repositories, the Phaser engine's own skill suite, Docker's container skills, a 124-listing hosted-API suite, two large plugin marketplaces, Circle's USDC payment skills, Superwall's iOS paywall suite, and app and media tooling suites. Four held for a later fire: amd/skills (11,103 across 15 listings), barty-bart/motion-graphics (10,793 across 6), mlflow/skills (10,709 across 21) and composio-community/skills (10,661 across 3).

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and skill layout from a fresh clone, and three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 48 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
