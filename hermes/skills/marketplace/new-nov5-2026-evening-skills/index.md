# New Skills - November 5, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 81 NEW rows and 260 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 313 installs. That makes the thirty-sixth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 66 sources and every source already had a catalog page, the single uncovered entry being a domain with no indexable listings, so neither standard lane produced a convert. The fire therefore drained the sized-candidate queue the November 5 morning fire left behind: nineteen sources already sized by their own repository, already re-tested against the current tree and already confirmed undocumented.

All nineteen were documented here, from 112.8K combined installs across 550 indexed listings: an Obsidian visual pack, a 253-skill cross-client library, a BMAD delivery toolkit, a Java review suite, a self-improving agent loop set, Rust desktop UI components, an onchain agent toolkit, Stream's chat and feeds SDK skills, Oracle's own technology skills, Alchemy blockchain skills, WPS Office automation, a browser tool that drives your own Chrome, Roblox game systems, a BMAD Claude Code plugin, Swift Testing guidance, a PowerPoint designer, a review and orchestration kit, a local-first memory system and Codex theme skills.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from a local clone, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 57 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
