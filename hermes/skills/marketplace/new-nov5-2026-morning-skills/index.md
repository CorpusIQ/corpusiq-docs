# New Skills - November 5, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 81 NEW rows and 260 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 313 installs. That makes the thirty-fifth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 66 sources and every one of them already had a catalog page, so neither standard lane produced a convert. The fire therefore drained the sized-candidate queue the November 4 evening fire left behind: 34 sources that were already sized by their own repository, already re-tested against the current tree and already confirmed undocumented.

The fifteen largest were documented here, from 128.8K combined installs across 96 indexed listings: Qt's official QML and C++ engineering skills, the next-safe-action form suite, a social-site CLI collection, Exa's own neural-search skills, an explainer-video pipeline, the Effect TypeScript suite, Payload's CMS skills, SASjs analytics skills, Terraform guidance from Anton Babenko, a spec-to-pull-request workflow, Margelo's React Native native-module skills, a knowledge-compile toolkit, an office-document suite and a Rust rule library. Nineteen sources remain queued above the floor for the next fire.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from the repository tree, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 45 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
