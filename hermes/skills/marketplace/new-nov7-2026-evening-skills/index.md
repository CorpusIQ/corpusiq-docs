# New Skills - November 7, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills across 0 failed queries: 81 NEW rows and 254 PARTIAL, with the top NEW row at 321 installs and no NEW source anywhere near the 1,000-install trigger. That is the fortieth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 63 sources with a single uncovered source, a domain that carries no indexable listings and whose best row reads 553 installs. Both standard lanes therefore produced nothing documentable.

With no queue left on disk, this fire ran a widened 144-query topic probe across business, engineering, design, data and growth territory: 10,653 unique skills, 0 failed queries. The probe returned 1,902 sources with no catalog page, 142 of which carried a row of 1,000 installs or more. Those were sized by repository against skills.sh, which left 32 sources at or above the 5,000-install floor once every row was filtered on the full owner/repo literal. Two carry standing dispositions and two repositories failed to clone, leaving thirteen documented here for 475,375 combined installs across 820 indexed listings.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from a shallow clone, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 26 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
