# New Skills - November 4, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 82 NEW, 259 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 308 installs. That makes the thirty-third consecutive fire in which the standard window was silent above that line.

All 57 repository-backed NEW sources were sized through their own owner query and every one stayed below the 5,000-install floor, the largest being simbajigege/book2skills at 1,025 across 46 listings. The trending board served 600 rows across 66 sources with a single uncovered source, archify.si, a domain with no repository and 1,164 board installs. Neither lane produced a convert, so the fire drained the queue the previous evening's widened 172-query topic probe left behind.

That queue held 228 sources sized by their own repository, 93 of them above the 5,000-install floor. Re-testing all 93 against the current catalog tree found 30 still undocumented, of which 27 resolved to a reachable repository with at least one SKILL.md file. The strongest 14 were documented here on install weight and relevance to Hermes agents: two game and 3D suites, a short-drama video pipeline, a presentation skill, three search and reference libraries, an official Brave Search pack, a Magento storefront suite, official Kotlin and DuckDB repositories, a diagram skill and a front-end craft library. Held back with reasons: modelscope.cn, developer.paddle.com and kie.ai have no source tree, mckruz/comfyui-expert is archived, and the standing 404kidwiz, zhaoxuya520, cyxzdev, gjkim42 and useosint dispositions are unchanged.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and skill layout from the GitHub trees API, and three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 42 gate runs passed on the orchestrator re-run against the canonical scripts, with zero fix cycles.
