# New Skills - November 6, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 81 NEW rows and 258 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 315 installs. That makes the thirty-seventh consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 66 sources and every source already had a catalog page, the single uncovered entry being a domain with no indexable listings. The queue from the November 5 fire was empty, so this fire ran a widened 231-query topic probe instead: 16,354 unique skills with 0 failed queries across 3,936 sources, 3,293 of them with no catalog page, 183 carrying a window row of at least 1,000 installs. Sizing all 183 by their own repository left 27 above the 5,000-install floor.

Nineteen of those cleared the standing dispositions and were documented here, from 232.3K combined installs across 450 indexed listings: a Claude Code plugin marketplace covering Azure and DevOps, a design-system judgment pack, Posit's R and Quarto skills, an Apple HIG reviewer, thirteen Instagram account skills, six video-editing skills, AMD's ROCm and Ryzen AI catalogue, MLflow's LLMOps skills, Composio Tool Router patterns, LiveKit's voice-agent lifecycle, SpriteCook game art, Sonilo audio, a starter-template set, the belt CLI skill, two design skills from Elaya, IART's WebGL and data-animation packs, an image-based PowerPoint skill and a SvelteKit kit.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from a local clone, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 57 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
