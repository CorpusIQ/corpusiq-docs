# New Skills - November 3, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 83 NEW, 259 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 308 installs. That makes the thirty-second consecutive fire in which the standard window was silent above that line.

All 59 NEW sources were sized by their own repository and every one stayed below the 5,000-install floor, the largest being soljourner/claude-engineering-skills at 1,639 across 36 listings. The trending board served 600 rows across 66 sources with two uncovered: archify.si, a domain with no repository, and vercel-labs/agent-desktop, which read as a single 1,081-install row and sizes at 5,077 across six listings. That board find is the thirteenth guide below.

The queue was empty after the previous fire, so this sweep probed instead. A widened 172-query topic probe covering cloud, security, languages, data and AI, product and growth, industry verticals, media production and agent infrastructure returned 12,634 unique skills with 0 failed queries across 3,165 sources. 2,632 of those sources have no page in the catalog; the 228 carrying a window row at or above 1,000 installs were sized by their own repository, and 93 cleared the 5,000-install floor. The thirteen below were chosen from that set on install weight, relevance to Hermes agents and breadth, after excluding the standing security exclusions (404kidwiz, zhaoxuya520, cyxzdev, gjkim42), the domain-only publishers that have no source tree (modelscope.cn, developer.paddle.com, kie.ai, playwriter.dev, docs.fish.audio, assets-tian.midao.site), equinor/fusion-skills which still has no reachable repository, and cheaper-inference/omniroute which is the same gateway already documented as diegosouzapw/OmniRoute and was reconciled in place instead of duplicated.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, the repository metadata and skill layout from the GitHub tree API, and three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 39 gate runs passed on the orchestrator re-run after an md5 comparison of the three canonical scripts.
