# New Skills - November 6, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 837 unique skills across 0 failed queries: 81 NEW rows and 249 PARTIAL, with no NEW source above the 1,000-install trigger and its top row reading 317 installs. That makes the thirty-eighth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 72 sources with two uncovered: a domain carrying no indexable listings and one source under the floor. The morning fire had already drained its probe queue, so this fire ran a second widened topic probe in fresh territory, covering framework and database specifics, SaaS tool integrations, business-process use cases, the finance stack, writing and research, engineering quality, analytics, verticals and agent-infrastructure constructs.

That probe returned 15,869 unique skills with 0 failed queries across 4,909 sources, 4,374 of them with no catalog page, and 108 carrying a window row of at least 1,000 installs. Sizing those 108 by their own repository left 33 above the 5,000-install floor. Sixteen cleared the standing dispositions and are documented here, for 313.5K combined installs across 341 indexed listings: Cognite Builder Skills (cognitedata/builder-skills, 45,575 / 38); Fandhe Agent CLI Skills (fandhe-ai/agent-cli-skills, 37,965 / 32); Paseo Skills (getpaseo/paseo, 32,407 / 14); Guizang PPT Skill (op7418/guizang-ppt-skill, 28,412 / 1); ZSXQ Skill (unnoo/zsxq-skill, 25,175 / 6); Spec Kit Skills (dceoy/speckit-agent-skills, 23,609 / 12); Claude Scholar (galaxy-dawn/claude-scholar, 19,910 / 57); PUA Skill (tanweai/pua, 19,212 / 34); daisyUI Skills (saadeghi/daisyui, 12,998 / 5); Story Skills (danjdewhurst/story-skills, 11,914 / 24); Rstack Skills (rstackjs/agent-skills, 11,707 / 24); AI Evals Skills (ai-evals-course/evals-skills, 9,483 / 11); ASD-STE100 Skill (danyuchn/asd-ste100-skill, 9,357 / 2); Tiangong Skills (tiangong-ai/agent-skills, 9,130 / 62); Dodo Payments Skills (dodopayments/skills, 9,036 / 18); ADHD Skill (uditakhourii/adhd, 7,589 / 1).

Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 48 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
