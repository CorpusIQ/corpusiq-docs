# New Skills - November 27, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog.

The standing 20-query window returned 886 unique listings with 70 uncovered rows, 206 partial rows and no failed queries. Its largest uncovered row was 160 installs for a graphic-design skill and its uncovered side carried 375 installs across 48 sources, so the window held no convertible cluster and a topic probe did the discovery work.

This fire probed agent infrastructure, office and document work, mobile development, databases, research agents, design tooling and code-drawn animation: 127 fresh lanes that returned 10,728 rows with no failed queries, 9,802 of them unique across 3,750 sources. Two publisher clusters then surfaced from the partial side rather than from the probe, because the install index had outrun the catalog: Expo's official skill suite and the Claude Office Skills collection were both cited inside existing pages but had no guide of their own.

## What These Publishers Cover

Document and office work leads the batch by install mass. The Claude Office Skills collection packages ninety-six office tasks as single-directory skills with an optional local MCP server, and it carries the largest combined install count of any publisher documented so far at 577,292 across 96 listings. Expo's official suite follows at 1,227,285 across 41 listings, covering native UI on both platforms, Expo Router, data fetching, builds, updates and SDK upgrades.

Engineering and data work come next. Turso documents its own SQLite-compatible engine for agents contributing to it, with the storage format, MVCC and transaction-correctness skills carrying the mass. Lightpanda ships a headless browser as a skill, BrowserOS ships an agent-first browser with per-agent tab groups, and Codely's harness covers plan phases, spec creation and conventional commits.

Research and creative work close the batch: GPT Researcher's skill exposes the open-source research agent, Lemo OpusCar packages ninety-nine film styles written as code, the Logo Design skill runs a full mark-and-brief workflow, iart's two skills draw every animation frame in JavaScript with the soundtrack synthesised in the same page, Alibaba Skill-Up evaluates and evolves skills against evidence, and Elite Long-Term Memory wires a write-ahead log, vector search and git-notes into one memory package.

## Method

Each publisher was sized with a strict source-equality filter over its full listing set, checked on the GitHub REST repository endpoint, and documented from its own README, SKILL.md files and skills.sh listing pages. Where the install index named a skill with no file in the current repository tree, the guide says so and takes that row's description from its skills.sh listing page rather than from an assumed file. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository actually contains.

## Held Back

The 127-lane probe surfaced a further queue rather than an empty market: AdsPower browser automation (4,253 probe installs), a Google Flights skill (3,183), a Core Data skill for Swift agents (2,594), a mini browser CLI (2,439), a Swift architecture skill (2,131) and a JavaScript animation collection (1,803) were all reachable and above 1,000 in the probe, and carry into the next fire. Five further publishers read above 1,300 in the probe but hold no repository worth documenting yet.
