## Notes on this batch

- Exact-source sizing again moved the order of the batch. `donchitos/claude-code-game-studios` read 4,998 installs from the probe and 49,825 across its 79 exact-source listings, a tenfold gap, and `timschoch/mattpocock-skills` moved 2,797 to 20,006. Ranking on probe rows alone would have put the fire's largest publisher in the middle of the list.
- Four guides ship Yellow and eight ship Orange; none ship Green. Three of the Orange guides carry a Fail on at least one auditor, three are Orange because the repository declares no licence at all or reports NOASSERTION rather than a standard one, and one is Orange for both reasons. `pymodel/react-frontend-skills` is the clearest case to read before installing: every skill passes Gen Agent Trust Hub and Socket, and four of the twelve sampled skills carry a Snyk Fail on the scanner's own rule set.
- `danielmiessler/lifeos` is a fast-moving repository with 19,939 stars, and a number of its indexed names have no matching skill directory in the current tree, including its top listing. Its guide says so rather than describing skills that cannot be reviewed.
- `shiplightai/agent-skills` is archived and read-only, and every skill in it depends on the Shiplight MCP server with a paid subscription for the cloud skill. The guide leads with that dependency instead of the install command.
- `zebbern/claude-code-guide` mixes two very different things: a long written Claude Code usage guide with everyday developer skills, and a large penetration-testing playbook set that supplies most of the top installs. The guide names both parts and keeps the offensive material in the Security discussion.
- Held with the reason named: `equinor/fusion-skills` (40,671 exact across 38 listings) and `404kidwiz/claude-supercode-skills` (20,036 across 96) and `vasilyu1983/ai-agents-public` (19,636 across 96) all answer 404 on GitHub, so their skill files cannot be reviewed; `sales-skills/sales`, `cold-iq/coldiq-s-gtm-skills` and `nymbo/skills` return zero rows from their own exact-source filter or no repository at all; `civitai/civitai` (4,948) is a platform monorepo where the indexed skills are incidental and needs a tree-scoped guide; `jmsktm/claude-settings` still has listing names containing spaces and slashes that a catalog table cannot carry.
- Queued for the next fire, sized and verified to resolve: `boristane/agent-skills` (4,997), `adjfks/corner-skills` (4,908), `juliobsz/skills` (4,886), `sylphxai/skills` (4,841), `bevibing/tutor-skills` (4,787), `nidhinjs/prompt-master` (4,777), `colosseumorg/colosseum-copilot` (4,508), `lawve-ai/awesome-legal-skills` (4,399), `oldwinter/skills` (4,313), `cuellarfr/design-skills` (4,305).
