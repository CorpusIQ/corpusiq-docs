## What These Publishers Cover

Framework ecosystems lead the batch. FastAPI's official repository ships a single agent skill behind a 105,048-star project, Astro carries the official framework skills for content-driven sites, Angular Best Practices collects framework guidance from a now-archived repository, and Superpowers Laravel applies the Superpowers workflow model to Laravel with a session hook that detects Sail and monorepos.

Two desktop and platform stacks follow: Claude Code Tauri Skills covers Tauri v2 setup, security and distribution across 39 skills, and the Elixir Phoenix plugin brings 26 specialist agents, Iron Laws enforcement and Tidewave MCP integration to LiveView work.

Video and design account for three more: Remotion Motion Graphics Skill adds cinematic camera, article highlight and terminal insert recipes to a Remotion workflow, Herk Edit Kit turns transcripts into cuts, story beats and publishable edits, and the Blender and Cinema 4D bridges in vladmdgolam Agent Skills give a design agent a render and feedback loop.

Data and backend work covers four: HelixDB pairs a knowledge-graph MCP with graph and vector queries, Wren AI turns natural-language questions into governed SQL through a semantic context layer, Altinity documents ClickHouse engineering for DBAs, and WooCommerce covers store building.

Drupal appears three times because three separate publishers maintain materially different Drupal suites: a code-component pack, a development and subagent suite, and a full Drupal 11 operating environment.

## Method

Each publisher was probed on skills.sh, sized with a strict source-equality filter over its full listing set, checked on the GitHub REST repository endpoint, and documented from its own README and SKILL.md files. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository tree actually contains.
