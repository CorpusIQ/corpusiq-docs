# New Skills - November 26, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog.

The standing 20-query window returned 886 unique listings with 71 uncovered rows, 206 partial rows and no failed queries. Its largest uncovered row was 18 installs for an email-automation skill and its uncovered side carried 248 installs across 48 sources, so the window again held no convertible cluster and a topic probe did the discovery work.

This fire probed a different axis from the morning batch: named SaaS and developer products rather than job phrases. CRM and support desks, finance and ERP systems, commerce platforms, observability and cloud infrastructure, developer platforms and AI tooling, regional and non-English markets, education systems, consumer hobbies, industry verticals, public-sector offices, role playbooks and agent infrastructure made up 297 fresh lanes. They returned 17,456 rows with no failed queries. Every shortlisted publisher was then sized through its own exact-source filter before ranking, because a probe row understates a large publisher by as much as five times in this market.

## What These Publishers Cover

Platform vendors lead the batch. Chalk ships a Claude Code and Codex plugin marketplace for its own compute platform, Cloudflare's skill migrates Next.js applications onto vinext, SonarSource wires SonarQube quality gates into the agent coding loop, Weights & Biases covers experiment tracking and agent tracing, and OllyGarden supplies vendor-neutral OpenTelemetry knowledge.

Media and content work follows: OpenMotion turns a reference video into editable motion graphics and rendered MP4s, Video Lens turns a YouTube link into a timestamped brief, and ZRT AI Lab's largest cluster automates Chinese short-video editing, Douyin and WeChat publishing.

Language work appears three times on different continents: Coji's natural Japanese rewriting, the Korean humanizer in IM NOT AI, and the Hebrew and RTL family in Skills IL.

Enterprise and operations close the batch: Serac pairs a ServiceNow MCP server with 73 skill guides, Canvas LMS brings classroom workflows over an MCP server, PeterHdd ships role-based engineering personas, prompts.chat exposes its prompt library as lookup and translation skills, and bkt gives agents a Bitbucket CLI with gh-like ergonomics.

## Method

Each publisher was probed on skills.sh, sized with a strict source-equality filter over its full listing set, checked on the GitHub REST repository endpoint, and documented from its own README and SKILL.md files. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository tree actually contains.

Seven candidates returned a non-200 on the GitHub REST repository endpoint and were dropped without sizing: equinor/fusion-skills, 404kidwiz/claude-supercode-skills, sales-skills/sales, scientiacapital/skills, vasilyu1983/ai-agents-public, shino369/claude-code-personal-workspace and the non-repository host evlog.dev.
