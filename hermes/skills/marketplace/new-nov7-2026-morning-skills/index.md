# New Skills - November 7, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills across 0 failed queries: 81 NEW rows and 258 PARTIAL, with no NEW source above the 1,000-install trigger and its top row reading 319 installs. That makes the thirty-ninth consecutive fire in which the standard window was silent above that line.

The trending board served 600 rows across 71 sources with two uncovered: a domain carrying no indexable listings and one source whose best row reads 752 installs, under the floor. Owner queries on all five NEW sources carrying a row of 100 or more installs returned at most 948 combined, so the standard lanes produced nothing documentable this fire.

The November 6 evening fire had left its sized candidate list on disk, so this fire re-tested all 108 sources it had sized rather than probing again. Thirty-three sat at or above the 5,000-install floor; seventeen had no catalog page; four carry standing dispositions and were held. The remaining thirteen are documented here, for 96.1K combined installs across 207 indexed listings: Astro Skills (astrolicious/agent-skills, 18,959 / 1); Graphite Skills (withgraphite/agent-skills, 9,989 / 1); Korean Skills (daleseo/korean-skills, 8,457 / 3); ModelStudio Skills (modelstudioai/skills, 7,703 / 13); 10x CLI Skills (przeprogramowani/10x-cli, 6,668 / 3); Alan Skills (supatest-ai/alan-skills, 6,365 / 6); HVE Core (microsoft/hve-core, 5,822 / 107); Unslop (theclaymethod/unslop, 5,624 / 1); pg-aiguide (timescale/pg-aiguide, 5,562 / 12); DingTalk Skills (breath57/dingtalk-skills, 5,476 / 10); React Router Skills (remix-run/agent-skills, 5,250 / 3); CC Godot (zate/cc-godot, 5,217 / 4); Julianromli Skills (julianromli/ai-skills, 5,054 / 43).

Every guide was built from a pre-verified pack holding the exact per-listing install figures, repository metadata and the real skill layout read from a local shallow clone, with three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 39 gate runs passed on the orchestrator re-run against md5-verified canonical scripts.
