# New Skills - November 20, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog.

The standing 20-query window returned 885 unique listings across 291 distinct sources with 79 uncovered rows and no failed queries. Its top row was 381 installs for `sjy051/music-composition`, followed by 312 for `selfdriven-octo/skillzeb` and 230 for `noamseg/interview-coach-skill`, so the window itself carried no convertible cluster. A 203-lane topic probe across creative, engineering, industry and back-office work carried the discovery, and every shortlisted publisher was sized through its own exact-source filter before ranking.

## What Shipped

Frontend and content work lead the batch. `aladicf/better-web-ui` gives a coding agent design judgment for web interfaces across React, Next.js, Vue, Svelte, Astro and plain HTML, with 33 skills and an all-Pass sampled security record. Canghe's Chinese-first suite covers image, video and comic generation and publishing to WeChat, Xiaohongshu, Douyin and X, and Hairline supplies 33 pointer-responsive isometric line figures with two skills that draw or rebuild one.

Native app and agent infrastructure sit behind them. BAMA turns a reference Mac app into a screenshot-driven backlog and builds it one story per commit in Swift and SwiftUI, OpenFang exposes 60 bundled skills and autonomous Hands inside a Rust agent operating system, and Simota ships 90 specialist agents behind a Nexus routing layer with a make-based installer that updates all three supported CLIs at once.

Two workflow suites and two safety suites complete the batch. Absolute is an eleven-skill development workflow engine with a daily build loop and an engineering health family, Full Stack Recipes encodes one assembled Next.js and AI SDK stack as atomic recipes an agent can fetch as Markdown, Newsjack turns an agent into a PR team from newsjacking detection to AI visibility, Transilience covers penetration testing from reconnaissance to CVSS 4.0 reporting for authorised engagements, and Accessibility Agents enforces WCAG 2.2 AA across web, document and markdown review with 113 skills and an edit gate.

## Method

The standing window ran first, then the probe as three foreground slices at 2.7 second pacing, writing per-lane JSONL so a kill loses nothing. Every candidate was then sized through its own exact-source filter, because the probe reads several times short at the top of the band: the largest exact sizes here sit far above their probe rows, so ranking by probe alone would have ordered the batch wrongly. Twenty sampled security verdicts per publisher fed the quality tiers.
