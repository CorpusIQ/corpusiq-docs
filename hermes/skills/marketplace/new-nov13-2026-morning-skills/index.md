# New Skills - November 13, 2026 Morning Sweep

The Nov 12 evening note asked for the query list to be widened rather than for the floor to be lowered, because the top of the uncovered band had fallen for three consecutive fires. ## New pitfalls found this fire

- **A null licence in the GitHub API is not proof of a missing licence file.** `gauss314/skills` reports `license: null` from the repository metadata, and the pack carried no licence, but `GET /contents/` lists a `LICENSE` file and the raw file opens with an MIT header dated 2026. The guide ships MIT on the evidence of the file. Probe the contents listing or the raw `LICENSE` before writing a no-licence claim, and when the two sources disagree, name both.
- **A prose claim the gates cannot see is the easiest one to get wrong.** The first gasserane draft said the pack ships "no scripts and no dependencies". The tree holds 76 Python files, three PowerShell files and a WAV test fixture. Format gates check frontmatter, tables and footers; they do not read sentences. Every no-scripts, no-dependency or read-only claim needs a file-extension count from the tree first.
- **Widening the query lanes is what restores the band, not lowering the floor.** 87 generic queries returned 2 uncovered sources above 3,000 installs on Nov 12 evening. 174 queries covering verticals, product, communications and personal productivity returned 8. The install mass was never missing, it was outside the lane list.
- **A subagent reporting green gates is a self-report.** All 13 drafts came back green from four drafting children and all 39 gate runs passed on the orchestrator re-run, but the two defects that mattered were invisible to every gate: the false no-scripts claim and a security sentence that miscounted passes. Re-run the gates yourself and read the prose against the tree.
- **A listing name with a space or a slash is invisible to both verifiers.** `gingiris` serves a listing called `AI Product Global Launch Playbook` and `qfeius` serves one called `skills/makeui`; neither matches the row regex, so gate 2 silently counts one fewer row. Tail arithmetic must be computed from the pack's EXACT ROWS and the API listing count, never from a gate summary line.
