## What These Publishers Cover

The batch splits into four groups.

Developer workflow and platform tooling accounts for six guides: Rheinmir Overstack at 16,840 installs is a complete Vietnamese-language personal agent harness with onboarding, propose, plan and verification loops; FuDesign2008 Open Skills is a Jira and git operations library; TestMu AI Skills brings device-cloud test automation; Eve Skillpacks packages one commercial platform; Darkmatter Skills is a team catalogue spanning TypeScript, Effect and shadcn work; Khasky Agent Skills concentrates on code review and audits.

Quality assurance and academic writing account for four: Awesome QA Skills covers the test lifecycle bilingually, UI/UX Agent Skill System gives vendor-neutral design judgment, Research Paper Lifecycle Skills spans literature review to submission, and Awesome Security Skills is an offensive toolkit that belongs behind an authorization gate.

Cloud and framework guidance accounts for three: AWS Agent Plugins and AWS Well-Architected Skills carry AWS's own plugin and review material, and Next.js 16 Agent Skills targets the current Next.js, Prisma and AI SDK releases.

Knowledge and people operations account for three: Claude Obsidian builds a self-organizing Markdown second brain, Novel Writer Skills is a Chinese fiction writing suite, and Manager Skills covers engineering management routines.

## Method

Each publisher was probed on skills.sh, sized with a strict source-equality filter over the full listing set, checked on the GitHub REST repository endpoint, and documented from its own README and SKILL.md files. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository tree actually contains.

## Held Back

Four candidates were checked and not documented this fire: `scientiacapital/skills`, `iamzhihuix/happy-claude-skills` and `camacho/ai-skills` returned 404 on the GitHub REST repository endpoint, and `backstage.io` resolved to a documentation host rather than a repository.
