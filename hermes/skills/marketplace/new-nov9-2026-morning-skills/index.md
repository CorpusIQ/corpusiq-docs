# New Skills - November 9, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills across 0 failed queries: 81 NEW rows and 253 PARTIAL, with the top NEW row at 958 installs and nothing above the 1,000-install trigger. That is the forty-third consecutive silent window.

The trending board served 600 rows across 67 sources. Two sources had no catalog page and both sat under the 1,000-install floor, at 908 and 461 installs. The board carried nothing above the floor either.

Both standard lanes were therefore silent, so this fire probed fresh territory: 117 topic queries across domains the standing window never asks about, 6,052 unique rows after de-duplication, 3,122 distinct sources and one failed query. Sizing every uncovered source by its own repository rather than by its best window row left twelve publisher clusters above the documentation floor, and all twelve are written here.

Every guide was built from a pre-verified pack holding the exact per-listing install figure for every indexed skill, the repository metadata, the real skill layout read from the GitHub tree and the frontmatter description of each skill. Each draft was then checked with three gates: the format gate, the pack cross-check at threshold zero and the frontmatter audit. All 36 gate runs are green on the orchestrator re-run against the canonical scripts.
