# New Skills - November 25, 2026 Evening Sweep

The standing 20-query window returned 886 unique listings across 290 distinct sources with 71 uncovered rows, 206 partial rows and no failed queries. Its largest uncovered row was 71 installs, and the uncovered side carried 316 installs in total across 49 sources, so the window again held no convertible cluster and a topic probe did the discovery work.

This fire probed different territory than the morning's vendor and platform lanes: micro-vertical trades and field services, regulated standards and certifications, locale-specific business operations, and role-level job functions across finance, supply chain, clinical administration, platform engineering and security operations. Every shortlisted publisher was then sized through its own exact-source filter before ranking, because a probe row understates a large publisher by an order of magnitude, and 100 exact sizes ordered the batch.

## What These Publishers Cover

Context and workflow harnesses lead the batch. Continuous Claude keeps agent state in ledgers and handoffs so multi-agent work survives a session boundary, Comet turns an idea into an evaluated, resumable workflow, Easy Cheese packages one software workflow behind nine portable skills, and Goal Workflow drives a feature from a requirements document to shipped code.

Specification and design work accounts for three: Allium is a behavioural specification language an agent maintains beside the code, StyleSeed is a design-method engine that converts one agent skill into a repeatable interface process, and Boraoztunc Skills collects copywriting, advertising, SEO and motion skills.

Execution and analysis account for four: Flue lets an agent drive desktop applications from the shell without an MCP server, GitNexus indexes a codebase into a symbol and dependency graph an agent can query, DeepSeek Stack adds planning, verification and review skills tuned for cheaper models, and Grimoire gives agents a readable language for financial intent across Aave, Uniswap, Morpho, Hyperliquid and Polymarket.

Domain suites round out the batch: Nansen CLI covers onchain research and wallet operations, Nonlooped Roblox Suite writes production Luau, and Blockbench MCP covers 3D modelling work through the Blockbench MCP plugin.

## Method

Each publisher was probed on skills.sh, sized with a strict source-equality filter over the full listing set, checked on the GitHub REST repository endpoint, and documented from its own README and SKILL.md files. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository tree actually contains.

## Held Back

`michael-denyer/pstack-claude` (67,202 exact across 69 listings) and `mdsmithaustin/pstack` (14,137 across 67) were held: both are derivative forks of the pstack corpus already documented as [PStack Skills](/hermes/skills/catalog/pstack-setup). `gargantuax/openskills`, `dedalus-erp-pas/foundation-skills` and `fittings-sh/fittings` returned 404 on the GitHub REST repository endpoint.
