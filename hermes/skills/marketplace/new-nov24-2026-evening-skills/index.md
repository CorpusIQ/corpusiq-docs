# New Skills - November 24, 2026 Evening Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog.

The standing 20-query window returned 886 unique listings across 290 distinct sources with 72 uncovered rows, 207 partial rows and no failed queries. Its largest row was 79 installs, and the uncovered side held only 50 sources worth 331 installs in total, so the window again carried no convertible cluster and a topic probe did the discovery work.

This fire probed vendor and product ecosystems rather than industries or workflows: ERP and finance systems, analytics and data platforms, agent frameworks and gateways, billing and payments, marketing and support suites, HR and legal tools, healthcare and construction systems, logistics and warehousing, cloud and platform engineering, and ecommerce and CMS platforms. Every shortlisted publisher was then sized through its own exact-source filter before ranking, because a probe row understates a large publisher by an order of magnitude, and 90 exact sizes ordered the batch.

## What These Publishers Cover

Design and frontend tooling leads the batch. UI Design Skills converts 87 shipped product interfaces into constraint files an agent reads before it writes CSS, and the Framer Motion and Linegel suites cover animation and Three.js WebGPU work respectively; Figma Console MCP Skills turns design-system inventory, token export and accessibility scanning into repeatable agent steps.

Platform and cloud operations account for four: Render Agent Skills is the official Render collection for deploys, Postgres, cron jobs and blueprints; Zeabur Agent Skills drives that platform from the CLI; Flux CD Agent Skills covers GitOps reconciliation and cluster debugging; and ilteoood Harness pairs 44 curated skills with the scripts that provision the machines agents run on.

Business operations and integration account for three: Pipa Skills layers service-business workflows from opportunity to client retention, MuleSoft DX carries Anypoint platform development and policy work, and COG Second Brain builds a versioned Markdown knowledge loop with daily and weekly reviews.

Commerce and mobile round out the batch: Saleor Agent Skills covers ecommerce storefront and app development, WeChat Skyline Skills documents WeChat's rendering engine for Mini Program work, and cmux Skills supports a Ghostty-based terminal built for agents.

## Method

Each publisher was probed on skills.sh, sized with a strict source-equality filter over the full listing set, checked on the GitHub REST repository endpoint, and documented from its own README and SKILL.md files. Every guide states its install band, its licence, its sampled security verdicts and the drift between what skills.sh indexes and what the repository tree actually contains.

## Held Back

`useosint/skills` was held: it is the same publisher and corpus already documented as [OSINT Skills](/hermes/skills/catalog/osint-skills-setup), now served under a renamed source. `sales-skills/sales`, `404kidwiz/claude-supercode-skills`, `iamzhihuix/happy-claude-skills`, `scientiacapital/skills` and `timschoch/skilly` returned 404 on the GitHub REST repository endpoint.
