# New Skills - November 2, 2026 Morning Sweep

Sweep of [skills.sh](https://skills.sh) for Hermes-relevant agent skills, cross-referenced against the existing catalog. The standing 20-query window returned 885 unique skills with 0 failed queries: 84 NEW, 262 PARTIAL, and no NEW source above the 1,000-install trigger, its top row reading 304 installs. The trending board served 600 rows across 63 sources.

Because the queue was empty after the November 1 evening fire, this sweep probed instead. A widened 68-query topic probe (data, marketing, design, engineering, business operations, media and agent infrastructure) returned 5,019 unique skills with 0 failed queries and 668 sources with no page in the catalog. Each was sized by its own repository rather than by its best window row, which is what turns a 222-install board sample into a 43,921-install publisher: 34 sources cleared the 5,000-install floor, and the 13 largest were documented here.

Every guide was built from a pre-verified pack holding the exact per-listing install figures, a depth-1 clone with its branch, licence and skill directories, and three-auditor verdicts sampled across each index. Each draft was then checked with three gates: the format gate, the pack cross-check at a per-guide threshold and the frontmatter audit. All 39 gate runs passed on the orchestrator re-run after an md5 comparison of the three canonical scripts, with no fix cycles.
