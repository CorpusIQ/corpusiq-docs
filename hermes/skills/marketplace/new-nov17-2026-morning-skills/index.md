## Notes on this batch

- Exact-source sizing ran before ranking, and the gap it closed was the largest recorded so far: `wanshuiyin/auto-claude-code-research-in-sleep` read 2,760 installs from 6 probe rows and 44,004 across 88 exact-source listings, a 15.9x miss that would have placed the batch's biggest publisher seventh. `lyndonkl/claude` moved 2,923 to 12,850 and `mckruz/comfyui-expert` 3,476 to 13,445 on the same pass.
- Security verdicts were read from the skills.sh skill pages for each sampled skill and carried verbatim. Three guides ship Green, four Yellow and three Orange. Four of the ten carry a Fail on at least one auditor, and one is Yellow for a missing LICENSE file rather than for a verdict.
- Two repositories carry a status a reader needs before installing: `mckruz/comfyui-expert` is archived and `lyndonkl/claude` ships no LICENSE file. Both are stated on the GitHub line, the tier line and in Limitations.
- Held with the reason named: `equinor/fusion-skills` (40,671 combined across 38 listings, but `github.com/equinor/fusion-skills` answers 404, so there is no public tree to verify or install from), `404kidwiz/claude-supercode-skills` (20,036 across 96 listings, GitHub 404), `iamzhihuix/happy-claude-skills` (5,950, GitHub 404), plus `bankrbot/claude-plugins` (14,547) and `teneoprotocolai/teneo-skills` (11,104), both real repositories held on class density in a batch that already carries three engineering publishers.
