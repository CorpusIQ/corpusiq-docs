## Notes on this batch

- Exact-source sizing ran before ranking, and the gap it closed was again at the top of the band: `haowjy/creative-writing-skills` read 2,334 installs from the probe and 19,508 across 58 exact-source listings, an 8.4x miss, and `promovaweb/specsfy` moved 2,617 to 21,220. Ranking on probe rows alone would have placed the batch's largest publisher seventh.
- Security verdicts were read from the skills.sh skill pages for each sampled skill and carried verbatim. One guide ships Green, nine Yellow and three Orange. Four of the thirteen carry a Fail on at least one auditor, and one is Yellow for a missing LICENSE file rather than for a verdict.
- `bankrbot/claude-plugins` carries no verdict at all: skills.sh publishes no Gen Agent Trust Hub, Socket or Snyk result for any of its listings, so its Security section states that plainly, names the skills that sign or broadcast transactions, and keeps the Orange tier. `teneoprotocolai/teneo-skills` ships no LICENSE file and `promovaweb/specsfy` is AGPL-3.0 copyleft; both are stated on the GitHub line, the tier line and in Limitations.
- Held with the reason named: `vasilyu1983/ai-agents-public` (19,636 combined across 96 listings) and `iamzhihuix/happy-claude-skills` (5,950 across 13 listings) both answer 404 on GitHub, and `sales-skills/sales` returns no rows at all from its own exact-source filter. Sized and held on class density instead: `wsimmonds/claude-nextjs-skills` (4,795), `adjfks/corner-skills` (4,907), `sylphxai/skills` (4,841) and `zrt-ai-lab/opencode-skills` (3,682), each a second suite in a class this batch already covers.
