# CorpusIQ Email Connectors

## What It Is

CorpusIQ connects to Gmail and Microsoft Outlook via OAuth, giving AI agents read-only retrieval access to email. Agents can search an inbox, list recent messages, and read full message content - always with the user's own permissions. Nothing is written back to the mailbox.

## Available Connectors

| Connector | Description |
|-----------|-------------|
| Gmail connector | List and search messages, read full message content |
| Outlook connector | List and search Outlook/Microsoft 365 mail, read full message content, mailbox folder counts |

## Quick Start

Add the connector through the [CorpusIQ dashboard](https://corpusiq.io/dashboard). Both connectors authenticate with OAuth - no API keys to manage.
