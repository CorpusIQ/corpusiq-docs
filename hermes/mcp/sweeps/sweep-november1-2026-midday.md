## New: the fleet is the unit of work

[Royally MCP](/hermes/mcp/servers/external/royally-mcp/) is remote Streamable HTTP at `https://app.royally.io/mcp`, carried in the official registry as `io.royally/royally` at version **0.0.898** with status **active** and `statusChangedAt` on **2026-11-01T04:1xZ**. A keyless `initialize` answered **HTTP 401** with `{"error":"missing_bearer_token"}`, so the surface is live and gated rather than absent.

Two URL shapes are worth recording because both read like a delisting and neither is one. `royally.io/mcp` returns **404**, the endpoint is on the `app.` host; and `app.royally.io/.well-known/oauth-protected-resource` returns **404** with no protected-resource document, so the auth shape is established by the 401 body and the vendor documentation rather than by discovery metadata.

The architecture is a cloud command layer plus a plugin on every site. An agent holds one connection instead of twenty site endpoints, and the plugin is what lets Royally read a site and make a change it can reverse. The change flow is the entry. A request is recorded with who asked and which sites it touches, held inside an approval window that can expire, optionally behind two-person approval and per-site-group rules, applied, and returned as a receipt naming who asked, who approved, what changed on which site and the one click that puts it back. The receipts collect into a fleet-wide log described as tamper-evident, so an edit to the record itself shows, and the log exports on a signed path. Safe jobs such as a page cache purge after a menu edit run without the queue, on the same reasoning that keeps a rollback fast.

Around that queue the fleet jobs run through the plugins the sites already have: updates with a backup taken first and automatic rollback, vulnerability and administrator-change alerts through GuardPress, Wordfence or Kadence, backup health through SiteVault or UpdraftPlus, uptime every five minutes with certificate, domain, page-speed and PHP fatal error checks routed to email, Slack, Discord or a signed webhook, bulk SEO titles and descriptions and menu items and custom CSS and template copies, WooCommerce prices and stock and orders with a seven-day undo, Elementor builds that wait for approval with a preview link first, SEO audits pulling Search Console and Analytics data through Rank Math and SEOSbolt, and weekly or monthly client reports in the agency's own brand beside a read-only client portal.

Pricing read directly: Solo **$89 a year** for 3 sites and 2 seats, Freelancer **$249** for 5 sites and 3 seats, Studio **$390** for 25 sites and 5 seats, each including the site plugin, the approvals, the receipts, the undo and the fleet jobs. An Agency tier adds white-label and developer extras at a price this pass did not read.

**Why it earns a guide.** Every WordPress entry in this catalogue is single-site. The official Automattic server works on WordPress.com hosted sites and the SSO connector handles identity on one installation; neither carries an approval queue, applies one change across a fleet or leaves a receipt per change. Royally is also the first entry here that governs **other MCP servers** rather than only its own tools: its documentation covers connecting the WordPress MCP Adapter, Easy MCP AI and the Elementor MCP behind the same connection under the stated rule that only Royally makes the change. That is supervision rather than a plugin list, and it is the same argument the tool-call audit entries have been making from the other direction.

**Gap recorded.** The endpoint is gated, so the **tool count and tool names are the vendor's publication and not a measured list**, and no `tools/list` was driven. The site plugin, the backup-first update path, the automatic rollback, the seven-day WooCommerce undo and the tamper-evident log are vendor claims this pass could not execute against a live site. The homepage states plainly that its example sites and receipts are invented, so nothing on that page is evidence. The registry record sits at **0.0.898**, which reads as a pre-1.0 surface that moves often.
