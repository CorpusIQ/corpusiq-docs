    MCP Server Discovery - October 23, 2026 (Evening Sweep)¶

    An eight-hour delta after the midday supplement closed, and the productive lane was the submission window again: eighteen issues, #5994 through #6011, read in full. The directories were nearly silent. The mcp.so feed carried thirty cards with exactly one posted after the previous capture, and mcpservers.org /all pages 1 to 3 returned ninety unique slugs against ninety at the supplement, every one already dispositioned once the brand-name slugs were unravelled.

    One entry cleared the bar, and it is the first surface in this catalog that prices the marketplace rather than the product: what Etsy, eBay and Amazon actually take, itemised, dated and reproducible.

    Server Category What it does
    ShopTrueProfit MCP Commerce & E-Commerce Per-unit marketplace economics for Etsy, eBay.com (US) and Amazon.com (US, FBA and FBM): thirteen read-only tools covering fees, profit, margin, break-even price, the price needed for a target margin, and a three-way comparison of the same product. https://mcp.apify.com/?tools=vncntlabs/shoptrueprofit-fee-mcp hosted on Apify Standby, requiring an Apify API token: unauthenticated POST initialize returned HTTP 401 {"error":"invalid_token","error_description":"Missing or invalid access token. The drivable path is the MIT repository PravinrajV/shoptrueprofit-fee-mcp (created 2026-10-17, 0 stars, 68 files), which clones, builds and serves the same thirteen tools with no credential at all: npm install, npm run build, PORT=3311 node dist/http.js, and POST initialize returned HTTP 200 with serverInfo shoptrueprofit-fee-mcp 1.0.0 on protocol 2025-06-18, tools/list returning all thirteen. Driven with five real calls. ebay_profit at price 25, shipping_charged 5, item_cost 8, shipping_label_cost 4, promoted_listings_pct 5 returned "eBay profit $12.02 on $30.00 revenue (40.07% margin) after $5.98 fees and $12.00 costs. Reference lookups returned count: 11 eBay final-value-fee categories with the per-order fee rule and seller-performance options, count: 37 Amazon referral categories with rates, minimums and size tiers, and count: 12 Etsy Payments regions with processing rate, flat fee and currency. Every response carries a dated fee table - ebay-us-2026-10-16, amazon-us-2026-10-16, etsy-2026-10-13 - the engine file that produced it and an engine_sha256 for each, the assumptions applied, the sources as official Seller Central and marketplace help-centre URLs, and a calculator_url back to the seller-facing page the same engine drives. Official registry entry io.github.PravinrajV/shoptrueprofit-fee-mcp 1.0.0, active since 2026-10-17T14:12:06Z, published as an mcpb package with its own fileSha256. Gap named rather than claimed: the vendor's strongest accuracy statement is that the suite cross-checks this server against the website's own functions on 1,700+ cases including Amazon's and eBay's own worked examples, and that claim is not reproducible from a public clone - those tests need the private app source and skip themselves. npm test on the clone returned 94 passed and 31 skipped, the entire crosscheck.test.ts file among the skips, which the README states plainly rather than letting a green run imply otherwise. What a reader can run does pass: protocol, schemas, distribution, batch, packaging and an Apify Standby test on the real SDK. Also named in the entry rather than smoothed over: what is deliberately not modelled (eBay Store subscriptions; Etsy Ads cost-per-click, Etsy Plus, currency conversion and the Regulatory Operating Fee; Amazon's low-inventory, inbound-placement, returns-processing, aged-inventory and storage-utilisation surcharges, lithium battery fees, removal and disposal, the Overmax handling fee, and FBA rates after January 14 2027, which are unpublished and fall back to 2026 non-peak rates with a warning), the US-only marketplace scope, and a one-week-old repository with no stars.

    Source Behaviour Worth Recording¶

    A listing is not a deployment, and this cycle produced both halves of the failure. www-bubblav-com sits in the directory as a product page for a support-chat platform while the endpoint its own page implies returns a Vercel deployment-not-found. my-websearch is a slug the directory's sitemap knows and its detail route does not. Neither is a catalog candidate, and neither is visible to anyone who reads the directory rather than probes it.

    A keyless handshake is not a usable server. AppGoat answered initialize and tools/list with no credential at all - 29 tools enumerated, prompts advertised - and then returned 401 invalid_token on the first tools/call. PourWire, catalogued in the midday supplement, is the opposite case: keyless all the way through and drivable. The two look identical on a card and at handshake, and only a tools/call separates them. That is now three cycles in a row where the probe, not the listing, decided the entry.

    A directory slug is a URL, not a name. Half of this cycle's apparent newcomers were the same servers under their documentation URLs. Matching on the slug alone would have produced thirteen false positives in a single pass. The brand token in the slug, matched against the catalog's own text, is the only comparison that has held.
