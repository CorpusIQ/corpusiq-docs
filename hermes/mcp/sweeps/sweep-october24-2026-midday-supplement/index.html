    MCP Server Discovery - October 24, 2026 (Midday Supplement)¶

    An hour after the midday sweep closed, and nothing in the delta had moved. mcpservers.org still counted 17,243 servers, so /all pages 1 to 3 served the same 54 server cards. The mcp.so feed's newest card was still watchcron-mcp at 2026-10-24T16:08:41.930Z, which the midday pass had read and disposed of. The submission window advanced four issues, #6040 through #6043.

    What had moved was the record. The midday pass reported that every one of its 86 /all slugs carried a prior disposition. Re-reading each card against the catalog, all 184 sweep reports and the last-sweep ledger turned up fifteen names that appear nowhere in any of them, which means that line over-counted: either the cross-reference matched a fragment of a name that belongs to something else, or the disposition existed only in the pass's own memory of having seen it. Either way the reader was told a page had been read when part of it had not.

    One of the fifteen clears the bar, and it is the first employment-law surface in this catalog.

Every answer has the same shape, ergebnis, rechenweg, quellen with norm, official link, check date and confirmation status, fallen, naechster_schritt, hinweis, stand and herausgeber, and several source rows state that the value is not yet confirmed rather than presenting a stale rate as settled. Free and open: code MIT, content CC BY 4.0, no plan or tool limit, with the vendor's paid HR service for companies from ten employees behind it. Official registry entry com.lintelly/hr-deutschland 0.2.0 active since 2026-10-23T15:58:52Z, with npm and OCI packages for stdio and the streamable HTTP remote. Gap named rather than claimed: none needed, because the server is keyless and was driven end to end, which is rare in this catalog and the reason the entry rests on real answers rather than documentation. Limitations recorded rather than smoothed over: Germany only with no Austrian, Swiss or EU layer; general information and not legal advice for a case; the employer share inside the 603.00 to 2,000.00 euro transition band given as a lower bound; the U1 and U2 levies, the insolvency levy for regular employment and the employers liability contribution outside every cost figure; document tools that produce text and transmit nothing; no connection to a payroll or HR system; per-tool daily call counts in coarse bands even though inputs are not stored; and a repository created 2026-10-23 and pushed 2026-10-24 with 0 stars, 0 forks and one open issue under a single publishing account, so the law it encodes is checkable and its maintenance record is not yet.
