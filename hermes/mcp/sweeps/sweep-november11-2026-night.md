## Catalogued: Arcaeon, driven through eleven calls

**[Arcaeon MCP](/hermes/mcp/servers/external/arcaeon-mcp/)** is `io.arcaeon/arcaeon` **0.10.0**, MIT, a stdio Python server installed with `uvx --from arcaeon --with "mcp>=2.0.0,<3" arcaeon mcp`, published **2026-11-11T17:16:40Z**. It is the consolidation of thirteen packages into one (`arcaeon-ledger`, `arcaeon-adapter`, `arcaeon-receipt`, `arcaeon-audit`, `arcaeon-mcp-vet`, `arcaeon-once`, `arcaeon-compact`, `arcaeon-continuity`, `arcaeon-baseline`, `arcaeon-dedup`, `arcaeon-distill`, `arcaeon-meter`, `arcaeon-all`), and the registry records the migration: `io.arcaeon/adapter` now reads **deprecated** with the message `Merged into io.arcaeon/arcaeon`.

`initialize` answered `arcaeon` **0.10.0** on protocol `2025-06-18`; `tools/list` returned **19** tools, **17** free and two paid (`witness_pin`, `witness_renew`, both needing `ARCAEON_KEY`). Eleven calls were driven in one session and three of them are the argument for the entry:

- **The chain, tampered.** Two records appended (`search`/`weather`, then `send_email`/`ops`) verified as `rows: 2, chained: 2, breaks: 0`. One word was then changed in row one, `weather` to `sunshine`, outside the server, and `ledger_verify` returned `ok: false` with `first_break: "line 1: chain mismatch"`. Restoring the bytes returned `ok: true` again. The same response carries a `calls_record` block, a second hash-chained ledger of the MCP calls the server served, so hiding a served call means breaking two chains rather than one.
- **It graded our own server.** `vet_grade` on one of this profile's Python MCP servers returned `source_sha256` `a8bdaba8…`, nine checks and two findings: `unsafe-exec` **high** at line 105 (`subprocess.run(..., shell=True)`) and `audit-record` **medium** at line 118, where the presence gate passed, tamper-evidence passed, and **completeness and reconstructability failed** on a missing tool name, timestamp and argument digest. The report ships its own blind spots in the artifact, including the admission that the battery reads bytes and never sends them, so it would read a server that dies on invalid UTF-8 as clean.
- **A purchase that did not match.** `deal_mandate` recorded `acme-supply` up to `500.00` USD with mandate digest `sha256:json-c14n:v1:37ea6a58…`; the buyer's commit was written at `39.00` and the seller's at `41.00`; `deal_dispute` returned `ALTERED` at `commit#1` naming `mandate_digest` and `terms.total`, with `counts: buyer 2, seller 1`. `second_read_compare` on a missing ledger returned `COULD NOT LOOK` with exit `3` rather than a 0 percent agreement, which is the three-valued doctrine the README states: **exit 3 is never a pass**.

The limits are recorded as the vendor states them and they are unusually honest: tamper-evident is not tamper-proof, the witness is operated by the same people who ship the package, the daily anchor is a clock and not a party, truncation is caught only by a pin, and neither truth nor authorship is proven. Writing costs about **18 ms** a row, so 102,000 rows took roughly 22 minutes, while a 50 MB log verifies in about 2.5 seconds. This is the second Arcaeon page in the catalog and the two are not duplicates: the August guide covers `arcaeon-ledger` as a standalone pip install, this one covers the consolidated package with the source grader, the evidence pack and the deal tape. It enters beside [AgentKeyGate](/hermes/mcp/servers/external/agentkeygate-mcp/) on the credential side and [AnythingMCP](/hermes/mcp/servers/external/anythingmcp/) on the gateway side, as the evidence trail rather than the door.

## Ops details that held, and one that did not

- **Per-map counts beat stamps on this surface.** A `lastmod` cut-off returned **190** candidates where the per-map delta is **234** and the distinct-set delta across the day is **474**, because a re-index rewrites stamps on pages that were already counted. Read the per-map counts first and use the stamps only to order the queue.
- **The registry is faster than the feed.** Arcaeon's registry record was published at **17:16:40Z** and its mcp.so card appeared at **23:13Z**, a gap of nearly six hours, so a pass that reads only the feed lags a pass that queries the registry by candidate name.
- **A bulk publish is one event, not N discoveries.** 181 of the 190 stamps sit inside a 96-second span. Cohort the batch before evaluating it, or the same marketing pages are re-triaged every night.
- **`uv` resolves the package, `pip` names it.** The registry declares `uvx` with `--with "mcp>=2.0.0,<3"` and a positional `mcp` verb, and `uvx --from arcaeon ... arcaeon mcp --tools` prints the free and paid split without starting the server, which is the cheapest possible pre-flight for a stdio server.
