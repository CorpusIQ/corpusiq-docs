## New Servers Catalogued

| Server | Category | What it does |
|---|---|---|
| [PayloadPier MCP](/hermes/mcp/servers/external/payloadpier-mcp/) | Procurement / Finance | Supplier price-list comparison by exact SKU over Streamable HTTP at `payloadpier.com/api/mcp`. `compare_supplier_prices` takes an idempotent `operation_id` plus `old_rows` and `new_rows` snapshots and returns the unit-cost change, catching the increase hidden behind an unchanged case price when a pack size or minimum order changes, with the gross-margin impact of the delta. Three account and referral tools sit beside it. One included comparison unit, then $0.25 prepaid; scoped API key in the Authorization header. It is a comparator, not a supplier catalogue: you supply the rows. |
| [Double AIgents DSAR MCP](/hermes/mcp/servers/external/double-aigents-dsar-mcp/) | Compliance / Legal Operations | Free keyless read-only server at `www.doubleaigents.com/api/mcp` for UK, EU/EEA and Swiss data protection work. Ten tools: the DSAR response deadline with the rule that applies and the extension position, the personal data breach notification clock, breach triage, acknowledgement, extension and clarification letters, DSAR request scoping, DPIA and EU AI Act screening, UK HR retention periods and a DSAR search checklist. Every tool is labelled general information rather than legal advice, and nothing about a live request is stored between calls. |
| [TPSClear MCP](/hermes/mcp/servers/external/tpsclear-mcp/) | Sales Operations / Compliance | Pre-dial screening at `tpsclear.co.uk/api/mcp`. `screen_numbers` checks up to 1,000 numbers per call against the UK TPS and CTPS registers and returns one of six states per number (clean, tps-listed, ctps-listed, unknown, suppressed, consented), with an optional `campaign_ref` kept on the audit record; `wash_au_numbers` checks the ACMA Do Not Call Register; `check_dead_numbers` runs HLR lookups for live, switched off or dead mobiles; `get_account`, `set_company_name` and `buy_credits` handle the account, and the top-up is returned as a Stripe Checkout link a person pays. Test keys return UK fixtures free. Plans from 95 GBP per month ex VAT for 2,500 checks per 28 days, then 15 GBP per 1,000. |
| [AskHound MCP](/hermes/mcp/servers/external/askhound-mcp/) | Marketing / Demand Discovery | Demand discovery across Hacker News, Stack Exchange, Bluesky and GitHub: search the phrase that matches what you sell with a recency window, context words, negative terms and an intent floor, run saved packs that return only matches new since the last run, and record each conversation as replied, skipped or seen. Local stdio server (five tools, all four sources), a stateless remote endpoint at `askhound.haullabs.dev/api/mcp` (four tools, Stack Exchange and Bluesky only) and a CLI with `search`, `queries --competitor`, `pack save`, `pack run` and `mark`. Public APIs only, `GITHUB_TOKEN` raising search from 10 to 30 requests a minute, MIT source, one anonymous ping a day with an opt-out, `reply_policy` encoding disclosure-first replying, free to run locally |
