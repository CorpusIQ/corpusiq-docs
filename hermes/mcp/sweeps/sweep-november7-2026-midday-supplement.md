## Catalogued

- [DocPin MCP - Publish an Agent's HTML to a Link You Control](/hermes/mcp/servers/external/docpin-mcp/) - remote Streamable HTTP at `https://mcp.docpin.app/mcp`, OAuth with dynamic client registration and PKCE, and the tier documented from the server's own contract because there is no key to drive. A keyless `initialize` answers **401** with `WWW-Authenticate` naming `https://mcp.docpin.app/.well-known/oauth-protected-resource/mcp`, and that document answers **200** naming the resource, the authorization server on the same host, `bearer_methods_supported` of header, the resource name, and exactly **2** scopes: `publish` and `settings`. That two-scope split is the operational fact: a connection approved without the settings tick can publish pages and cannot touch branding, custom domains, members or billing. **The stable link is the entry.** Republishing the same `slug` publishes a new version **behind the same link**, so the URL in a client's bookmarks does not rot, and `rename_page` keeps the short link while redirecting the old addresses. Around that sit the four capabilities nobody else on the artifact shelf combines: `set_access` with `team`, `public`, `password`, `people` (emails and `@domains`) or `inherit`, where password and people-only pages need Pro and pages in a board follow the board; `list_versions` and `restore_version`; `get_page_views`, which on a people-only page reports **by whom**; and a per-page JSON store that `set_page_data` updates **without republishing**, read in the browser with `docpin.data()`. That last one is what a dashboard needs: layout and numbers are separate artifacts. `set_draft` to share requires an `access` value, so the agent has to ask who should be allowed in rather than defaulting to public, and `create_upload_link` takes a file up to **25 MB** through a one-time link that lives **15 minutes**. Page data is capped at **1 MB** and about **30 writes a minute** per workspace; a draft preview lives about an hour and is explicitly not for sharing. **Free** is 3 pages; **Pro $8 a month** adds unlimited pages, custom domains, password and people-only pages, and a smaller badge. The page itself runs in a sandboxed frame under `docpinusercontent.com` with cookies and IndexedDB blocked and `localStorage` kept per page per visitor, which makes it a place to read a report and filter a table, not a host for an authenticated app.
- [AgentKeyGate MCP - A Pass Instead of the API Key](/hermes/mcp/servers/external/agentkeygate-mcp/) - self-hosted gateway, Apache-2.0, Node.js 22, SQLite, Streamable HTTP at `https://{host}/mcp` behind a `gwa_...` agent token, **1.0.2** in the registry. A self-hosted product has no public endpoint to probe, so this guide documents the contract from the repository rather than driving it, and records that the vendor's own `Checked live` column reads **`no`** on **every** client snippet. **The four tools are the whole surface:** `list_services` returns the services this agent may use with each credential's mode, `max_ttl`, `max_calls`, the compiled filter and the live `access` state; `request_access` takes `service`, `ttl`, `calls` and a `reason` up to **200** characters and returns approved, pending with a `poll_after` of 5 seconds, or denied; `check_request` polls; `call` proxy-forwards with the key injected. Passes are `gwt_...` and the agent **never receives the service key**. **The data filter is why it earns the guide rather than a hold:** types and fields are chosen explicitly and everything else is cut from the JSON **before it reaches the agent**, routes outside the chosen types return `403`, `readOnly` is **on by default for CRM and support keys** (HubSpot, Pipedrive, Zendesk, Bitrix24, amoCRM) with blocked writes not consuming quota, and `mask` replaces e-mails, separated phones, Luhn-valid card numbers and IBANs. The vendor's own example is the clearest statement of the design: a Bitrix24 lead returns seven fields and the agent receives `ID`, `STATUS_ID` and `OPPORTUNITY`, with the client's name, phone and sales note gone. Weakening a filter needs a **fresh TOTP code** and shows a "was, now" page first, and "Check on one call" runs one real read as the owner, outside the agents' limits, logged, showing field names only. Providers include Bitrix24, amoCRM, HubSpot, Pipedrive, Zendesk, Stripe, GitHub, Slack, Notion, Linear, Airtable, Atlassian, Twilio, SendGrid, Resend, the LLM providers and an **Other** entry for any HTTPS API with a key in a header you name. Honest limits recorded: **0 stars**, created **2026-11-05**, single owner, no external audit, root on the server reads every key, masking does not find names, filters exist for only four services, and the `ssm` vault, Docker with a real certificate, macOS and Safari are the vendor's own untested list.

**Why they are two entries and not one.** The artifact shelf already carried owners for publishing ([HTML Pub](/hermes/mcp/servers/external/htmlpub-mcp/), a domain and a page) and for link presentation ([Shareglow](/hermes/mcp/servers/external/shareglow-mcp/)); DocPin is the delivery loop with access control, versions and a view log. The credential shelf carried secret *storage* ([1Password](/hermes/mcp/servers/external/1password-mcp)) and *action* approval ([lookfirst](/hermes/mcp/servers/external/lookfirst-mcp/), per-call HMAC over exact arguments); AgentKeyGate is credential **brokerage**, where the pass is bounded by a call count as well as a clock, which neither of the named comparables is described as doing.
