# MCP Server Discovery - October 20, 2026 (Night Sweep)

Night delta about five hours after the October 19 evening capture. The mcp.so `/feed` page 1 carried four cards posted inside the window (iGaming Tools at 36 minutes, a Patsnap patent and literature search at one hour, Coinrule at two hours, twocents at five) and the rest carried their evening dispositions. mcpservers.org `/all` pages 1 to 3 served 90 cards, and the useful signal this time was positional: everything stacked above the catalogued `drift` card was added since that capture, which separated genuinely new listings from the ones held a few hours earlier.

Four entries were catalogued, and the difference from the last several sweeps is that every one of them was verified by running it rather than by reading its listing. Two were run end to end on this machine (a Python proxy and a Node server), one was probed to its authentication boundary and its OAuth metadata read, and one was checked against its package registries and repository state.

| [Azquo MCP](/hermes/mcp/servers/external/azquo-mcp/) | Data and Analytics | Official hosted server at `https://data.azquo.ai/mcp` for Azquo, a finance-owned store where agents keep what they learn. Names live in hierarchies rather than rows, so a new dimension is a new lens instead of a migration, and every individual figure carries per-cell provenance back to its source file, the user and the date. Several agents and people work in one database with every write attributed to both the agent and the person behind it; conventions an agent agrees are stored in the database for the next agent. Capabilities, in the vendor's wording because no `tools/list` is reachable without a credential: create databases, import raw files, design import templates, query in AQL, browse and extend hierarchies, build and run reports, audit any figure through every transformation, rehearse a change on a copy, see a name's history and restore a deleted one. Verified: `initialize` returned HTTP 401 `Unauthorized : no key` with `WWW-Authenticate: Bearer resource_metadata="https://data.azquo.ai/.well-known/oauth-protected-resource"`, and that document returned `{"resource":"https://data.azquo.ai/mcp","authorization_servers":["https://data.azquo.ai"],"bearer_methods_supported":["header"],"scopes_supported":["mcp"],"resource_name":"Azquo"}`. Evaluation access on request, price unpublished. |

Three tools - `recent_leads` free and instant, `keyword_table` at about $0.05 a name plus $0.09 a call, `run_radar` paid and measured in minutes - and a keyword table that sizes the generic demand behind each new name and decides prioritize, watch or skip. PyPI 0.4.0, MIT, Python 3.10+; repository created October 12, 2026, pushed October 18, 1,218 stars, 436 forks. The worked example is checkable: `Niko1221/Strata`, created 2026-09-24, 7,700 stars nine days later, searched from 9/26 while no keyword tool listed it. About $15 a month on the example config. |
| [GLP Audit Proxy MCP](/hermes/mcp/servers/external/mcp-glp-audit-proxy/) | Compliance | Local stdio proxy (`pip install mcp-glp-audit-proxy`, 0.1.0, MIT, Python 3.11 to 3.13, alpha) that sits between an MCP host and its upstream servers and writes every mediated call, including denials and failures, as one RFC 8785 canonical-JSON line in an append-only SHA-256 chain with a `.head` sidecar. Role separation is enforced - `operator` calls upstream tools, `approver` approves, `qa` reads the trail, `admin` changes policy and cannot call upstream - and auditing cannot be switched off: `audit_enabled: false` is denied and logged. Installed and run here: eleven entries for one session, `glp_verify_chain` returned `chain ok entries=11 head=6669451c...`, the verify CLI returned `chain ok entries=12 shown=12` with a per-entry listing, and the tool surface differed by role exactly as documented (`operator` with no upstreams: `tools: []`; `qa`: `glp_verify_chain`, `glp_search_audit`, `glp_export_audit`). Coverage is mapped clause by clause to OECD GLP No. 17, FDA 21 CFR Part 11 11.10(e), EU GMP Annex 11, MHRA and PIC/S PI 041-1, WHO TRS 1033 and EU AI Act Articles 12 and 19. Community approval is not an electronic signature; WORM storage and signing are Pro. |
| [Creavores AEO Audit MCP](/hermes/mcp/servers/external/creavores-aeo-mcp/) | SEO | Local stdio Node server (`npx -y creavores-aeo-mcp`, npm 1.1.0, MIT, Les Creavores) that scores one page for AI-search readiness: crawlability 30, structure for AI extraction 35, E-E-A-T trust 35, plus separate `llms.txt` and AI-bot access checks. Eight tools verified by `tools/list`, including `check_agentic_readiness` (aligned with Lighthouse's Agentic Browsing category) and `simulate_ai_citation` (which passage an engine would extract, and why). Two live calls on a public marketing page returned `score: 100`, `verdict: "excellent"`, `issueCount: 0`, seven AI crawlers checked and none blocked, and an `llms.txt` compliance score of 100 with 13 sections and 37 links parsed. Filed as two stars rather than a gap-closer: Ranki already carries AEO scoring in this catalog and Prognosite carries SEO and AEO intelligence, so this is packaging and two angles at zero cost, no key and no rate limit. |
