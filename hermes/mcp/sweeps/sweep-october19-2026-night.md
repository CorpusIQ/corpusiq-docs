# MCP Server Discovery - October 19, 2026 (Night Sweep)

Night sweep about four and a half hours after the October 18 night sweep, so this one is a delta pass rather than a full window: the mcp.so `/feed` page 1 (30 cards, six of them posted since the previous capture) and page 2 (the next 21 cards, all carrying earlier dispositions), plus mcpservers.org `/all` pages 1-5 through the r.jina.ai reader proxy (150 slugs, page 1 rotated completely past the October 17 cohort), with vendor documentation and repository metadata for every candidate that survived the first pass. One new business-relevant entry, catalogued with a guide: an on-premises IT client management server whose entire write surface is gated on named human approval.

## New Servers Catalogued

| Server | Category | What it does |
|---|---|---|
| [ACMP MCP](/hermes/mcp/servers/external/acmp-mcp/) | Business Operations / IT | Self-hosted MCP server for Aagon ACMP, the German client and asset management platform. One Windows executable on your own ACMP server exposes 118 tools across ten areas - clients and inventory, installed software, CVEs, missing and failed updates, Defender and BitLocker state, licence over- and under-deployment, jobs and script history, client commands, the kiosk, containers, assets, contacts, locations, cost centres, contracts and expiring contracts, and 18 helpdesk tools including creating, updating, closing and commenting on tickets - plus `acmp_call` over all 167 Public API commands. The design centre is the approval gate: reads run immediately, a write freezes as a request with the PowerShell shown in clear text and runs after one named approver, and execute or delete waits for two different people, all decided in a browser outside the model. Per-operator API keys with optional binding to their real ACMP identity; approval logins are separate tokens. MIT, requires ACMP 6.9/6.10 with AESB/SICS and the Public API on Windows Server with .NET Framework 4.8. Documentation is in German. |
