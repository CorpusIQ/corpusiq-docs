# MCP Server Discovery - October 25, 2026 (Midday Supplement)

Fifty minutes separate this pass from the midday read, and neither surface moved in that gap. mcpservers.org served 17,360 at both captures, and mcp.so page one still carried thirty cards with the newest at `2026-10-25T13:50:07Z`, both of which the midday pass had already dispositioned. At a gap that short the listing work is repetition, so this pass went where a delta that small actually lands: the six submissions filed after `#6104`, read in full rather than by title.

One of them answers without a key, which makes it the rarest kind of find on this beat: a server that can be judged by driving it rather than by quoting its submission.

Seven were executed with real arguments in this sweep. The replay simulator dropped two copies of an event outside the 72 hour horizon and reported `naiveHandlerBug: APPLIED_EXPIRED_REPLAY_OUTSIDE_72H_WINDOW` with `naiveFinalTier: growth_59`, naming the paid tier a naive webhook handler would have granted from a stale event. `GR123456789` normalised to `EL123456789` and returned `FORMAT_VALID_UNVERIFIED` with `zeroRateAllowed: false` and `reverseChargeReason: LOCAL_FORMAT_CHECK_ONLY_NO_LIVE_VIES_CONSULTATION`, which is a format check refusing to authorise a zero rate. Limitations recorded rather than smoothed over: it is not a Stripe connector, since tools take billing objects as arguments or read telemetry forwarded to `POST /v1/events/ingest`, and nothing lists customers, invoices or revenue; `stage_stripe_dispute_ce3` was not called because it needs a live dispute shape across four nested objects, and its staging is `submit: false` by design with no external mutation; every VIES mode except `LIVE` is a deterministic simulation, kept so an operator can rehearse the HTTP 200 soft failure the Commission's service actually produces; there is no OAuth, as `/.well-known/oauth-protected-resource` on the API host returns 404, so the connection is a workspace key in the client config; and scope is B2B net terms in euro cents. ## Candidates Read and Held

**The six submissions filed after the midday cutoff were read in full, and five were held on class rather than on quality.**

- **`dbmole-mcp`** (`#6105`) and **`esmole-mcp`** (`#6106`), both from the same publisher: PostgreSQL and MySQL, or Elasticsearch 7.x and 8.x, where the agent adds and edits its own connections at runtime, with a per-project connection file that hot reloads, SSH tunnels with host key checks, readonly sessions enforced by the database itself, and a 40 KB result budget. Held in the database access class already carried by `WoWSQL` and the AI2SQL and AI for Database dispositions, and recorded as the cleanest implementation of agent managed connections seen on this beat, which is the thing to revisit if that class ever thins.
- **PLCWare TIA Openness** (`#6107`): 158 tools, 62 read only, over Siemens TIA Portal V21 through TIA Openness, with downloads gated on an explicit human approval of the generated plan and safety logic kept as a human decision. Held as industrial engineering tooling, because it is a thin client of a Windows desktop app that has to sit on the same machine as the portal licence, which puts it outside what an operator's hosted assistant can reach.
- **3ilm-mcp** (`#6108`): 1,032 findings from ten smart contract audit contests reconciled against the outcomes, in 12 pattern categories with accepted and rejected examples, keyless and MIT. Held as developer security reference data.
- **Shootika** (`#6109`): 14 tools over OAuth 2.1 that list a store's products, request an on-model shoot, return frames, and publish only what an operator approves. Held inside the media generation class that held Vadyu, Axiom Lab, Seedance3 and agent-media this month.

**On the listing side**, page one still carried 29 cards and every one resolved this pass. **BookHotels Direct** (`https://bookhotels.direct/mcp`, keyless, reads a hotel's own booking site and compares it like for like against Booking.com, saying so when Booking is cheaper) is the one name no catalog file, sweep report or ledger entry held, held here as consumer travel price comparison per the SlickTrip and Chucho Book Direct dispositions. **GSC Magic** carries its night sweep hold as Search Console, Bing Webmaster Tools and GA4 behind one hosted URL against the SEO class. **LFG Atlas** is a free gaming group directory for bots and overlays, held as consumer. **Stride**, a backlog server that reads and writes real stories and sprints for Claude Code, held as developer tooling beside the KanbanMCP disposition. `coolsapiens`, `getremcp`, `shbernal` and `leemysw` returned 404 detail pages through the reader proxy, which is the sitemap fresh but not live class rather than a finding, and the rest of the page carried prior dispositions.
