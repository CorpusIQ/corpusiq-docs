[offprompt MCP](/hermes/mcp/servers/external/offprompt-mcp/) is a local stdio package, `offprompt` **0.3.0** on npm, MIT, Node 22 or later, with **zero runtime dependencies** and a single `bin` entry, which for a tool whose whole job is handling secrets is the cheapest supply-chain check available and a real one. `npx offprompt init` runs in a project, detects the agents there and registers the server. When an agent needs a credential it calls `collect_secret`, a page opens on **127.0.0.1**, a person types the value, and it is written straight into `.env.local` or a named file; the agent receives the key's **name and a fingerprint** and never the value. `await_secret` covers the case where the agent must wait for the human step rather than race past it, and `cancel_secret` is the abort path a two-tool design usually forgets.

**65 provider formats** are validated as the value is typed. The timing is what matters: a wrong key caught at the page costs one retype, the same key written to a env file costs a 401 an hour later at the point where the agent is mid-task and reporting the wrong cause. The fingerprint is the decision worth copying, because a tool that returns only "ok" leaves the agent unable to tell a key it just collected from one already in the file, which is exactly how a production key ends up in a staging test. The distinction from the catalogue's [Vaultwarden MCP](/hermes/mcp/servers/external/vaultwarden-mcp/) is intake versus retrieval. The trade to make deliberately is the cloud-sandbox path, where a **Cloudflare quick tunnel** exposes the page because `127.0.0.1` inside a container is not the developer's laptop, and the property that makes local mode strong, that nothing leaves the machine, does not survive the move. **Gap recorded:** nothing was installed or executed, the three tool names are the vendor's publication, and whether the file write accepts any path the agent names, whether `await_secret` blocks or polls, and whether the tunnel is scoped to a single collection are each one install away from an answer.
