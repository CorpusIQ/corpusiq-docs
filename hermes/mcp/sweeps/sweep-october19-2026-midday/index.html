    MCP Server Discovery - October 19, 2026 (Midday Sweep)¶

    Midday delta about eight hours after the October 19 night capture. The interesting change is where the yield came from: the mcp.so /feed page 1 produced nine cards newer than the 03:10 capture and none of them cleared the bar, while mcpservers.org /all pages 1-4 - pulled through the r.jina.ai reader proxy because the origin answers a plain request with a 403 - produced 117 slugs, 42 of which are named nowhere in the night sweep or the two cycles before it. Two entries were catalogued with guides, and one of them closes a hole that had been open in this catalog since the beginning: there was no YouTube channel operations server at all.

    New Servers Catalogued¶

    Server Category What it does
    YouTube Kit MCP Social Media Management Local stdio server (uvx youtube-kit mcp) plus the ytk CLI, from the youtube-kit 0.6.0 PyPI package - Python 3.12+, MIT, github.com/eukosh/youtube-kit created August 21, 2026, last push October 19, 2026, two open issues, no stars yet. The operator's own channel as tools: analytics totals and breakdowns by day, month, video, country, device, OS, traffic source, playback location, age, gender and subscriber status; videos (get, categories, resumable upload with progress, metadata update, set thumbnail, wait for processing, like or dislike, rating, delete); comments (list published, held for review or likely spam, replies, post, reply, edit, delete, approve, hold, reject, ban the author); playlists (list, get, items, create, update, image, add, remove, move, delete); channel (get, recent activity, logged-in channels, about info, banner, watermark, home-page sections); search over videos, channels and playlists; subscriptions. Multi-channel: one ytk auth login per channel, --my-channel / my_channel per call, YOUTUBE_CHANNEL for a default. What makes it safe to leave connected: one JSON document per command on stdout, a JSON error object whose type is mirrored in the exit code (2 bad input through 10 timeout), quota cost printed in every --help and every tool description, two-step deletes that need a second call naming the exact target, damage limits that refuse to delete a video above 100 views or a public video older than 7 days, and idempotent already_gone results. Auth is your own Google Cloud project (YouTube Data API v3 plus YouTube Analytics API, Desktop OAuth client, about five minutes guided by ytk auth guide) because the 10,000-unit daily quota belongs to a project rather than a shared client: reads 1 unit, search 100 per page of 50, most writes 50, guarded deletes 52, an upload 1,600; Analytics runs on a separate quota. Not covered: captions, localizations, live streaming, channel memberships. Not affiliated with Google. Gap closed: the only other video-platform entry in the catalog is tiktok-transcript-mcp.
    PhilForms MCP Compliance Local stdio client (npx -y github:philforms/philforms-mcp, Node 18+, no dependencies, MIT) over the PhilForms HTTPS API - OpenAPI 3.1, api version 1.0.0, live at philforms.com/api/v1/openapi.json and stating 1,342 forms. Covers BIR, SSS, PhilHealth, Pag-IBIG, GSIS, COA, CSC and GPPB, with every input mapped to its printed box so a TIN lands digit by digit in its cells. Five tools: search_forms, get_form_parameters (the fill contract - parameter, label, type, format, choices), check_form_values (validate before filling, rendered as it would print), fill_form (PDF plus tamper-evident document id), verify_pdf (prove the file is unaltered). The wider documented API adds dossier, ingest, scan and extraction endpoints, a verification ledger and key rotation. The design decision worth recording: a value the form cannot hold is refused with the reason instead of being coerced, so a workflow fails at the check step rather than printing a plausible wrong certificate. Pricing in PHP from /api/v1/plans (200): free watermarked tier that still issues clean first-of-pack forms plus 5 clean 2307s a quarter and 5 clean 2316s a year, 500 test fills on a pk_test_ key, credits where fill costs 1 and check, preview and verify cost 0 (revise 0, within 7 days, at most 5 edits), packs at 79 PHP for one form and 299 PHP for five, valid 12 months. is_checkout_available was false at probe time, so the schedule is confirmed and the purchase path is not. Fills and prints; you file. Not affiliated with any agency.
